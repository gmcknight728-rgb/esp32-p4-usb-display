# ESP32-P4 USB Display - PC Application

This is the Windows PC application that captures your desktop and streams it to the ESP32-P4 display.

## Features (To be implemented)

- Desktop screen capture
- MJPEG compression for efficient streaming
- USB communication with ESP32
- Touch input handling (convert touch to mouse clicks)
- Mouse pointer tracking
- Keyboard support

## Requirements

- Python 3.7+
- pip packages (see requirements.txt)
- Windows 10/11
- USB driver for ESP32-P4

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
